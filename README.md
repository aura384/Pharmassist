# Pharmassist

Pharmassist is your personal healthcare companion — soft, intelligent, and quietly observant.
Think of it as a lightweight, AI-powered version of Baymax.

It helps you:

* understand medications you’re taking
* analyze side effects and interactions
* explore composition and risk levels
* bridge the gap between you and professional medical advice

A little clinical. A little caring. Slightly chaotic in curiosity.

## What it does

Pharmassist takes input about drugs or medications and:

* analyzes potential side effects
* evaluates severity / fatality risk (informational)
* explains composition in a simplified way
* gives contextual insights to help you stay informed

It doesn’t replace a doctor — it helps you ask better questions.

## Tech vibes

`ai` · `chatbot` · `health informatics` · `experimentation` · `curiosity-driven building`

## Setup

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
python app.py
```
